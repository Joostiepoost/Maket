# Temp

Joost's folder for test material (the bach rolls and other files a build step is tested on) and for things that come up while testing: test saves, crash reports, screen captures. The application never reads or writes here; the console test program reads the test material and lists what it finds in its report.

This repository is public. Nothing of conTimbre belongs in it: no database, no catalogue made from it, no orchestra files with sample names, no manual.
